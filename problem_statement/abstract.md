
> **AgentWAF is a production-oriented AI governance middleware designed to secure autonomous AI agents before they interact with enterprise tools and resources. Unlike conventional guardrail systems that focus primarily on prompt and response filtering, AgentWAF enforces security and governance at the action layer by intercepting every tool invocation generated by an AI agent. The system evaluates each request against configurable governance policies, including rate limiting, parameter validation, data-scope enforcement, workflow sequence validation, and human-in-the-loop approval mechanisms. Every decision—whether allowed, blocked, or escalated—is recorded through a comprehensive audit logging framework and visualized via a real-time monitoring dashboard. Built using FastAPI, React, Docker, and deployable on AWS, AgentWAF demonstrates how enterprise AI agents can operate safely, transparently, and in compliance with organizational governance policies while remaining provider-agnostic and extensible for future integrations.**
